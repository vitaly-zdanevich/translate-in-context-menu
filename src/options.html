Saved automatically. Used for the context menu, system notifications, the second-screen display, and Google Translate links. Source language is detected automatically. Yandex uses its own language settings.

Stored locally without encryption; not synced. Saving does not send a test request.

Get an API key

  1. Follow Google’s setup guide to create a project, enable billing, and enable Cloud Translation API.
  2. Open Google Cloud Credentials, select Create credentials → API key, and restrict the key to Cloud Translation API.
  3. Paste the key above and click Save.

Price

For typical personal use, such as translating words and short phrases, this extension should be free for you. The $10 credit is a free allowance, not a monthly fee.

Google Cloud Translation Basic NMT pricing in USD, checked September 26, 2026:

  • Free ($0) for the first 500,000 characters per month. Google applies this as a monthly $10 credit, shared across Cloud Translation Basic and Advanced.

Usage beyond the free allowance is billed; see Google’s official pricing.

System notification

Select text on a webpage and press Alt+Shift+N to show its translation in a system notification using your Google API key and selected target language. Firefox and your operating system control the appearance and duration; long translations may be shortened. Change the shortcut in about:addons → gear menu → Manage Extension Shortcuts.

Phone display

Keep the phone display open on the same local network. Select text in Firefox and press Alt+Shift+T. You can change this shortcut in Firefox’s Manage Extension Shortcuts screen.

Yandex Translate

Open Yandex Translate in another Firefox window, select text in your working window, and press Alt+Shift+Y. This replaces Yandex’s text field using its current language settings. No API key or local server is needed.
